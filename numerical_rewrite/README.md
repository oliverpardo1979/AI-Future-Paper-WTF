# Numerical results for the paper

This folder contains the admitted equilibrium paths and numerical audits used
in [*The Future of Growth and Human Labor Under Recursive AI
Self-Improvement*](../main_rewrite.tex).

The files are generated by the public workflow documented in
[`REPLICATION.md`](../REPLICATION.md). From the repository root, run:

```text
python scripts/reproduce_rewrite_results.py
```

`equilibrium_paths.csv` contains the plotted trajectories.
`sigma_*_audit.json` records the equilibrium-admission tests for each
elasticity. The two `sigma_1_50_support_*.json` files record the additional
Hamiltonian-support tests used for the high-substitution case. The manifest
files link the exported data and figures to the audited numerical checkpoints.

These files should be regenerated through the public workflow rather than
edited directly. A converged boundary-value calculation is only a candidate;
the workflow exports it as a paper result only after all admission checks pass.
